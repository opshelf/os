config_hardware.json is config file for Openshelf hardware modules (src/hardware).
This is read by config.py module to create a config dictionary that can be accessed (get/set) by modules.
For now we'll store config for all modules in one file, may be segregated in the future.  

{
    "<module name/file>": {
        "<parameter>": <value>,
        ...
    }
    ...
}

Naming rules: 
1. Suffix parameter with units where relevant.
